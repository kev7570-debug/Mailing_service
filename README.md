## Функциональность

### Основной функционал
- **Управление клиентами** — добавление, просмотр, редактирование и удаление получателей рассылок.
- **Управление сообщениями** — создание и редактирование шаблонов писем.
- **Управление рассылками** — планирование, запуск и отслеживание статуса (`Создана` / `Запущена` / `Завершена`).
- **Отправка по требованию** — ручной запуск рассылки через интерфейс или командную строку.
- **История попыток** — логирование каждой отправки с указанием статуса и ответа почтового сервера.
- **Статистика** — отображение общего количества рассылок, активных и уникальных получателей на главной странице.

### Аутентификация и права доступа
- Регистрация, вход и выход из системы.
- **Обычный пользователь** — управление только своими рассылками, клиентами и сообщениями.
- **Менеджер** — просмотр всех данных, блокировка пользователей и отключение рассылок (через админку Django).

### Производительность
- Кеширование страниц (главная) и низкоуровневое кеширование списков для снижения нагрузки на базу данных.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kev7570-debug/Mailing_service.git
cd Mailing_service
```

### 2. Настройка виртуального окружения

```bash
python -m venv venv
# Активация:
venv\Scripts\activate      # Windows
# source venv/bin/activate # Linux/Mac
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание суперпользователя (для доступа в админку)

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Работа с рассылкой

### Через интерфейс

1. Создайте клиента (`/clients/create/`).
2. Создайте сообщение (`/messages/create/`).
3. Создайте рассылку (`/mailings/create/`), выбрав сообщение и получателей.
4. На странице деталей рассылки нажмите **«Отправить сейчас»**.

### Через командную строку

```bash
python manage.py send_mailing <id_рассылки>
```

## Настройка почты (опционально)

Для использования реального SMTP-сервера замените в `settings.py`:

```python
EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
EMAIL_HOST = 'smtp.yandex.ru'
EMAIL_PORT = 465
EMAIL_USE_SSL = True
EMAIL_HOST_USER = 'ваш_логин@yandex.ru'
EMAIL_HOST_PASSWORD = 'пароль_приложения'
DEFAULT_FROM_EMAIL = EMAIL_HOST_USER
```

> По умолчанию используется консольный бэкенд (`console.EmailBackend`) для тестирования без реальной отправки.
